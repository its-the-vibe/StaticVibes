# NeonBeats

NeonBeats is a responsive, touch-friendly music playground built with
TypeScript, PixiJS, and the Web Audio API. Create sounds, play a simple rhythm
game, and explore animated visuals in a neon-styled interface.

## Features

- **Pad Synth:** Play eight sound pads and trigger visual effects.
- **Rhythm Rush:** Tap falling notes when they reach the target zones and build
  your score.
- **Visualizer:** Tap animated nodes to play tones and create particle effects.
- **Three presets:** Cyber, Retrowave, and Cosmic change the sound and color
  palette.
- **Responsive layout:** Designed for touch screens and desktop browsers.

## Getting started

You’ll need Node.js and npm installed.

```sh
npm install
npm run start
```

Open the local URL printed by Vite in your browser. Sound starts after your
first interaction with the page, as required by browser audio policies.

## Scripts

| Command | Description |
| --- | --- |
| `npm run start` | Start the Vite development server. |
| `npm run build` | Run linting and TypeScript checks, then create a production build in `dist/`. |
| `npm run lint` | Lint the project. |

## Tech stack

- TypeScript
- PixiJS
